# codex-previews

Static host for Codex HTML previews, meant for phone checks in mobile Safari.

GitHub Pages publishes the `main` branch from the repository root (`/`).

- Hub: https://hangji0713-tech.github.io/codex-previews/
- Tokyo Michelin: https://hangji0713-tech.github.io/codex-previews/tokyo-michelin/

A `.nojekyll` file is present so Pages serves these files as-is. Photo credits for the Michelin preview are in `tokyo-michelin/images/CREDITS.md`.
